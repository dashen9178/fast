FAST 隐私政策与用户协议

适用范围：FAST 编辑器（Android 版、Windows 桌面版）
生效日期：2026 年 11 月 3 日　|　最近更新：2026 年 11 月 3 日

FAST 是一个本地积木编程编辑器。我们尽量少收集数据，下面说明具体范围。

1. 保存在本机的数据

你创建的作品、页面、代码块、界面设置保存在本机（Windows 版保存在本机应用数据目录）。卸载后可能一并删除，请自行导出备份。这类数据不会自动上传。

2. 账号与社区（可选）

只有你主动登录或发布时才会使用：

  • 邮箱：用于登录验证和账号识别；
  • 发布到社区的作品：作品名称、介绍、图标、作品文件以及评论内容会对其他用户公开可见；
  • 点赞、收藏、浏览记录：用于展示个人主页。

不使用账号与社区功能时，无需登录，也不会提交上述信息。

3. 网络服务

账号、社区、评论、检查更新通过阿里云函数计算中转；安装包与作品附件存放在阿里云 OSS；数据另做 GitHub 私有仓库备份。AI 助手仅在你自行填写 DeepSeek API Key 后使用，请求直接发往 DeepSeek。除此之外不向第三方提供你的数据。

4. 设备权限

Android 版：存储（导入/导出作品与安装包）、通知（显示「作品正在运行」和结束入口）、安装未知应用（安装你自己导出的作品或更新包）。以上权限均只在你主动使用对应功能时使用。

Windows 版：仅使用本地文件读写（保存作品、导出安装包）与网络访问（账号/社区/检查更新）。不申请摄像头、麦克风、通讯录、定位等权限。

5. 我们不收集

通讯录、短信、精确位置、相册全量内容、设备唯一标识用于广告画像等均不收集，也不接入广告 SDK，不做行为画像广告。

6. 你的权利

可随时退出登录、删除自己发布的社区作品与评论；如需删除账号数据，可通过下方联系方式联系开发者处理。

7. 未成年人

请在监护人指导下使用；社区发布内容请勿包含个人隐私信息。
